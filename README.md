# Search Router

A simple alternative to DuckDuckGo bangs.  

Redirects search queries to different search engines using custom keywords.  
The code is designed to be deployed on Cloudflare Workers.  

You can try it here: [https://searchrouter.adamskri.eu/?q=](https://searchrouter.adamskri.eu/?q=)  
Note: the query should be appended after `?q=`.
